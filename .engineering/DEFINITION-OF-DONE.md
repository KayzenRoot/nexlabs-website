# Definition of Done

## Completed: GEF bootstrap

NEXLABS-WO-001-GEF-BOOTSTRAP is approved and merged.

## Completed: M01 — Product Foundation & Visual System

M01 is approved and merged. Its product scope, information architecture, visual direction, architecture decisions, quality targets and implementation boundaries are canonical.

## M02 — Runtime & Repository Foundation

M02 is complete only when:

1. A clean checkout can install deterministically with `npm ci`.
2. Next.js App Router and strict TypeScript are implemented without entering 3D scope.
3. Design tokens, global base styles and reusable layout primitives are in place.
4. Home has a semantic static shell with immediate no-WebGL hero fallback, valid anchors and no fabricated business claims.
5. Lint, typecheck, unit/component tests and production build pass.
6. Chromium browser smoke and automated accessibility checks pass.
7. Keyboard focus, skip link, reduced motion and representative responsive viewports have retained evidence.
8. CI exposes stable green `CI Quality` and `Browser Smoke` checks.
9. Main ruleset/repository merge settings enforce the admitted professional gate, or objective permissions evidence yields BLOCKED.
10. The GEF 1.1.2 pin/private package invariant remains intact.
11. No M03-M07 scope enters the diff.
12. Evidence Bundle and proposed Checkpoint Delta are complete.
13. Exact-head independent review reports no unresolved HIGH/CRITICAL finding.
14. Canonical checkpoint is promoted only after APPROVED.
15. The PR is merged only after approval.

## Website implementation increments

Each implementation Work Order must be FUNCIONAL + TESTADA + DOCUMENTADA + DEPLOYABLE + objectively validated within its admitted scope. Required checks include lint, typecheck, build, relevant unit/integration tests, accessibility checks and performance evidence where affected. Visual increments additionally require screenshot/reference comparison evidence at defined viewport sizes.
