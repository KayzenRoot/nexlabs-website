# Requirements

## Bootstrap requirements

- The official repository is KayzenRoot/nexlabs-website and main is the base branch.
- Node.js version is at least 22; npm and Git are functional.
- GitHub CLI is authenticated when available, and its observed repository capability is recorded.
- The sole direct GEF dependency is @gef-bootstrap/cli pinned exactly to 1.1.2 in package.json and package-lock.json.
- Run and record npx gef --version, npx gef --help, npx gef init --json before npx gef init --apply, npx gef doctor, and npx gef status.
- Create the Work Order, Context Lock, checkpoint, scope, requirements, architecture, security, validation plan, deployment policy, backlog, decisions/ADRs, and Source Pack index.
- Do not implement product code in this increment.
- Keep the PR open and unmerged.

## Product requirements

No product or website requirements have been admitted. The first product Work Order must define them from approved source material.
