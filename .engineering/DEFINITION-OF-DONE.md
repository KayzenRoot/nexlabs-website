# Definition of Done

## Completed: GEF bootstrap

NEXLABS-WO-001-GEF-BOOTSTRAP is approved and merged.

## Completed: M01 — Product Foundation & Visual System

M01 is approved and merged.

## Completed: M02 — Runtime & Repository Foundation

M02 is approved and merged after exact-head review with all required CI, Browser Smoke, Socket Security and CodeRabbit gates green. Its runtime, testing, Docker and repository-governance foundation is canonical.

## M03 — Brand System & N Monogram planning

M03 planning is complete only when:

1. The N monogram concept brief is precise enough to generate/evaluate alternatives consistently.
2. The monogram has explicit requirements for silhouette, geometry, recognizability, favicon behavior and monochrome use.
3. Logo lockups, spacing, minimum-size and inverse/dark-background rules are defined.
4. Typography strategy is defined with production/licensing constraints.
5. Color/material roles are finalized for flat and enhanced chrome/glass presentations.
6. Motion states are defined for intro, idle, hover and reduced-motion without requiring WebGL.
7. The concept-generation process defines a target set, shortlist method and objective rejection criteria.
8. Final implementation deliverables and acceptance evidence are explicit.
9. No final logo asset is silently selected during planning.
10. Exact-head independent review reports no unresolved HIGH/CRITICAL finding.
11. The planning PR is merged before implementation begins.

## Website implementation increments

Each implementation Work Order must be functional, tested, documented, deployable and objectively validated within its admitted scope. Runnable frontend increments must leave the approved development Docker environment running/healthy unless the owner explicitly instructs otherwise.
